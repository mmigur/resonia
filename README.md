# Resonia — PWA для тренировки вокала

React + TypeScript + Vite, UI на shadcn/ui (Tailwind v4, иконки lucide), база и авторизация — Supabase,
определение высоты тона — модель SPICE (TensorFlow.js) прямо в браузере.

Сценарий: сплэш с логотипом → пение строчки → экран загрузки с этапами анализа → подробный разбор голоса →
регистрация → дорожная карта из 20 уроков (4 раздела, как в Duolingo) → профиль с «вокальным паспортом», награды, прогресс.

## Запуск (VS Code)

Нужен Node.js 18+ (проверка: `node -v`).

```bash
npm install
cp .env.example .env     # затем заполни .env (см. ниже)
npm run dev
```

Открой http://localhost:5173 и разреши доступ к микрофону. Пой в наушниках.
Без заполненного `.env` весь сценарий до регистрации работает, а форма входа покажет подсказку.

## Подключение Supabase

### 1. Создай проект
supabase.com → New project. Дождись, пока он поднимется.

### 2. Создай таблицы
Dashboard → **SQL Editor** → New query → вставь содержимое `supabase/schema.sql` → **Run**.
Если базу уже создавал по старой версии — выполни ещё `supabase/migrations/002_session_metrics.sql` (колонка `metrics` для подробных метрик; без неё приложение работает, но метрики занятий не сохраняются).
Скрипт создаёт таблицы `profiles`, `sessions`, `achievements`, включает Row Level Security
(каждый пользователь видит только свои данные), триггер автосоздания профиля и функцию удаления аккаунта.

### 3. Вставь ключи — вот куда
В корне проекта (рядом с `package.json`) лежит `.env.example`. Скопируй его в файл **`.env`** и заполни две строки:

```
VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJ...   (или sb_publishable_...)
```

Где взять значения: Dashboard проекта → **Project Settings → API** (в новых проектах — кнопка **Connect**).

- `Project URL` → в `VITE_SUPABASE_URL`
- ключ **anon public** (или **publishable**) → в `VITE_SUPABASE_ANON_KEY`

После правки `.env` перезапусти `npm run dev`.

**Важно:** вставляй только публичный ключ (anon / publishable). Ключ `service_role` / `secret`
обходит защиту данных: его нельзя класть в проект и нельзя отправлять в чат. Публичный ключ безопасен
в браузере именно потому, что данные защищены политиками RLS из `schema.sql`.

### 4. Настрой подтверждение e-mail
Authentication → Providers → Email.
- Для разработки отключи **Confirm email**: регистрация сразу пускает в приложение.
- Если оставить включённым, после регистрации придёт письмо со ссылкой; приложение попросит подтвердить e-mail.
  Результат теста сохранится и запишется в профиль после первого входа. На бесплатном тарифе встроенная
  почта Supabase ограничена по числу писем в час.

## Деплой (для установки PWA и микрофона на телефоне нужен HTTPS)

Netlify / Vercel / Cloudflare Pages: команда сборки `npm run build`, папка `dist`.
Те же две переменные `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` добавь в настройках хостинга (Environment variables).
Затем в Supabase: Authentication → URL Configuration → Site URL = адрес сайта.

## Структура

```
src/lib/dsp.js         анализ пения: ноты, баллы, уровень, метрики голоса (покрыт тестами)
src/lib/songs.js       мелодии и слова песен (слова можно менять)
src/lib/exercises.js   тест, разделы и уроки карты, достижения
src/lib/metrics.js     пояснения к метрикам (ts)
src/components/SingStage.tsx  анимированная сцена пения
src/lib/spice.js       загрузка SPICE и инференс; запасной детектор, если модель недоступна
src/lib/audio.js       микрофон, эталонные тона, запись
src/lib/attempt.ts     сценарий попытки: слушать → отсчёт → петь → анализ (экран загрузки)
src/lib/api.ts         запросы к Supabase
src/lib/auth.tsx       сессия и данные пользователя
src/components/ui/     компоненты shadcn/ui
src/screens/           экраны
supabase/schema.sql    схема БД
public/logo.svg        логотип (PNG-иконки PWA — public/icons)
```

## Что проверено, а что нет

Проверено: типы (tsc), production-сборка, тесты DSP, прохождение сценария
«сплэш → тест → экран загрузки → результат», карта, урок, профиль и прогресс в headless Chrome с имитацией микрофона и подменой ответов Supabase (экраны и вёрстка проверены, содержательные оценки на тональном сигнале — нет).

Не проверено (в среде разработки не было доступа к этим сервисам):
- загрузка настоящей модели SPICE с TF Hub (при недоступности приложение переходит на упрощённый детектор
  и показывает бейдж «Упрощённый режим»);
- работа с живым Supabase: регистрация, вход, запись прогресса, `schema.sql`.
  Первый прогон лучше сделать на свежем тестовом аккаунте;
- установка на телефон и поведение на iOS Safari.

## Известные ограничения

- Песни: мелодия народной «Калинки» (общественное достояние), слова авторские («Рябинка») — чужие тексты не воспроизводятся. Свои слова: `src/lib/songs.js`, один слог на ноту.
- Вибрато завышает «неровность» звука; метрики ориентировочные, не медицинская оценка голоса.
- Запись через `ScriptProcessorNode` (устарел, но работает везде); позже заменить на `AudioWorklet`.
- Порядок выходов SPICE определяется автоматически сверкой с автокорреляцией; проверь на реальной модели.
- Бандл около 1,7 МБ (TensorFlow.js); он кэшируется service worker'ом.
